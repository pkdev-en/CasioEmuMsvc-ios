# 📲 Guide to Installing CasioEmuMsvc on iOS

> This guide is for **iPhone/iPad** users who want to install the Casio emulator on iOS.

---

## 📋 Requirements

- iPhone / iPad running **iOS 14 or later**
- **Apple ID** (a free Apple account is sufficient)
- **SideStore** installed and set up on the device
- **CasioEmuMsvc.ipa** file (download from [GitHub Releases](https://github.com/pkdev-en/CasioEmuMsvc-ios/releases))

---

## 🔧 Step 1 — Install SideStore (if not already installed)

> If you already have SideStore, skip this step and go straight to Step 2.

Go to [sidestore.io](https://sidestore.io) and follow the instructions.

---

## 📥 Step 2 — Download the IPA file

1. Access the **Releases** page of the repo:  
   👉 [github.com/pkdev-en/CasioEmuMsvc-ios/releases](https://github.com/pkdev-en/CasioEmuMsvc-ios/releases)
2. Download the latest **`CasioEmuMsvc`** file.
3. Save the file to **Files → On this iPhone** (or iCloud Drive).

---

## 📲 Step 3 — Install the Emulator

### Install via SideStore

1. Open the **SideStore** app on your iPhone.
2. Switch to the **My Apps** tab (app icon in the bottom bar).
3. Tap the **＋** sign in the upper right corner.
4. Select the file you just downloaded → tap **Open**.
5. Log in with your Apple ID if prompted, then tap **Install**.
6. Wait a few seconds — the app will appear on your home screen.

> If you are in **Vietnam**, download **VPN Super**, open it, select **United Kingdom**, turn it on, and then enable **LocalDevVPN**.

---

### Install via TrollStore

> ⚠️ **TrollStore only supports iOS 14.0 – 16.6.1 and iOS 17.0 exclusively.**  
> If your device runs iOS 17.0.1 or later, or iOS 18+, please use SideStore above instead.

**Advantage of TrollStore:** The app is installed **permanently** — no 7-day expiration like SideStore.

#### Install TrollStore (if not already installed)

The installation method varies depending on your iOS version and device model.  
👉 Follow the official guide at: **[ios.cfw.guide/installing-trollstore](https://ios.cfw.guide/installing-trollstore/)**

#### Install CasioEmuMsvc via TrollStore

1. Download the **`CasioEmuMsvc.ipa`** file from [GitHub Releases](https://github.com/pkdev-en/CasioEmuMsvc-ios/releases) to your device.
2. Open the **Files** app and navigate to the downloaded `.ipa` file.
3. Tap the `.ipa` file to open it.
4. Tap **Share** → scroll through the list and tap **TrollStore**.
5. TrollStore will install the app automatically — **no renewal needed, no computer required**.
6. The app will appear on your home screen within a few seconds.

---

## ✅ Step 4 — First Launch

1. Open **CasioEmuMsvc** from the home screen.
2. Tap the **Import** button.
3. Select the Casio emulator you want to import (`.package` extension).
4. Enter the password.
5. After entering the password, tap **all** and you will see your emulator.
6. Tap on your chosen emulator and tap **Launch**.
7. Enjoy! 🥳

---

# NOTES:

## 🔄 Renew your app (SideStore only — not needed with TrollStore)

Free Apple ID only signs apps valid for **7 days**. To renew:

- Open **SideStore**, connect to the **LocalDevVPN**, and go to **My Apps**.
- Tap **Refresh All** or tap the app name and select **Refresh**.
- Turn on **Background Refresh** in SideStore Settings for automatic renewal.

> **Tip:** Use **LiveContainer** if you want to install more apps than the 3-app limit of your free Apple ID :)

---

## ❗ Common Errors

| Error | Solution |
|-------|----------|
| App deleted after 7 days | Renew via SideStore before expiration |
| Cannot connect to SideStore VPN | Check the **pairing file** in SideStore Settings |
| Error "App could not be installed" | Ensure you trust the certificate in iOS Settings |
| TrollStore says iOS not supported | Your iOS > 17.0 — use SideStore instead |
